Cách càiHow to install

Android
  1. Mở trang này trên điện thoại Android và bấm tải về.
  2. Khi tải xong, mở file .apk (trong thông báo, hoặc ứng dụng Tệp / Files → Tải xuống).
  3. Nếu điện thoại hỏi, chọn Cài đặt → bật Cho phép từ nguồn này, rồi quay lại.
  4. Bấm Cài đặt. Nếu Google Play Protect cảnh báo, chọn Thêm chi tiết → Vẫn cài đặt.
  5. Mở ứng dụng Nhạc Nhẽo là nghe được ngay, không cần tài khoản.

Ứng dụng cài cạnh bản SimpMusic chính thức, dữ liệu để riêng. Khi có bản mới, ứng dụng sẽ tự hỏi để cập nhật.

  1. Open this page on your Android phone and tap Download.
  2. Open the downloaded .apk, from the notification or from Files → Downloads.
  3. If asked, allow installing from this source, then go back.
  4. Tap Install. If Google Play Protect warns you, choose More details → Install anyway. It warns because this build isn't from the Play Store.
  5. Open Nhạc Nhẽo. No account needed to start listening.

It installs next to the official SimpMusic app and keeps its own data. The app offers new versions by itself.

Windows
  1. Tải SimpMusic-Windows-installer.zip về.
  2. Trước khi mở, chuột phải vào file zip → Properties, tích ô Unblock ở dưới cùng rồi bấm OK. Bỏ qua bước này thì Smart App Control sẽ chặn trình cài đặt. Không thấy ô Unblock thì cứ làm tiếp.
  3. Chuột phải vào file zip → Extract All → Extract.
  4. Trong thư mục vừa giải nén, bấm đúp vào install.bat rồi chọn Yes. Ứng dụng sẽ được cài và tự mở, sau này tìm trong Start Menu với tên SimpMusic.

Nếu Windows vẫn chặn install.bat, cài thủ công trong cùng thư mục: bấm đúp simpmusic.crt → Install Certificate → Local Machine → Next → Place all certificates in the following store → Browse → Trusted People → OK → Next → Finish, rồi bấm đúp file .msix → Install.

Ứng dụng được ký bằng chứng chỉ riêng chứ không phải chứng chỉ trả phí, nên máy cần được báo là tin chứng chỉ này một lần.

  1. Download SimpMusic-Windows-installer.zip.
  2. Before opening it, right-click the zip → Properties, tick Unblock at the bottom, then OK. Skip this and Smart App Control blocks the installer. No Unblock box means you can just go on.
  3. Right-click the zip → Extract All → Extract.
  4. In the extracted folder, double-click install.bat and click Yes. It installs the app and opens it. You'll find it in the Start Menu as SimpMusic.

If Windows still blocks install.bat, install by hand from the same folder: double-click simpmusic.crt → Install Certificate → Local Machine → Next → Place all certificates in the following store → Browse → Trusted People → OK → Next → Finish, then double-click the .msix file → Install.

The app is signed with its own certificate rather than a paid one, so this PC has to be told to trust it once.

Mac
  1. Không chắc máy bạn là loại nào? Bấm menu Apple → About This Mac: thấy Chip: Apple M… là Apple Silicon, thấy Processor: Intel là Intel.
  2. Mở file .dmg vừa tải rồi kéo SimpMusic vào Applications.
  3. Mở SimpMusic trong Applications. Nếu máy hỏi có mở ứng dụng tải từ internet không, bấm Open.

Cần macOS 15 Sequoia trở lên. Trên Mac, ứng dụng có tên SimpMusic. Nếu máy đã có bản SimpMusic chính thức, bản này sẽ thay thế nó và giữ nguyên thư viện cùng cài đặt.

  1. Not sure which Mac you have? Apple menu → About This Mac: Chip: Apple M… is Apple Silicon, Processor: Intel is Intel.
  2. Open the downloaded .dmg and drag SimpMusic onto Applications.
  3. Open SimpMusic from Applications. If your Mac asks whether to open an app downloaded from the internet, click Open.

Needs macOS 15 Sequoia or later. On a Mac it's called SimpMusic. If you already have the official SimpMusic desktop app, this replaces it and keeps its library and settings.

Nhạc Nhẽo là bản fork cá nhân, không chính thức, của SimpMusic (maxrave-dev và cộng sự), không liên kết với và không được YouTube, Google, Apple, Spotify hay dự án SimpMusic bảo trợ. Các nhãn hiệu thuộc về chủ sở hữu của chúng.

Dự án không lưu hay đăng tải âm thanh, video. Nhạc được phát từ server của YouTube và thuộc về chủ sở hữu bản quyền. Phần mềm được cung cấp "NGUYÊN TRẠNG", không có bảo hành. Dùng ứng dụng bên thứ ba có thể trái với điều khoản của các nền tảng mà app kết nối đến; bạn tự chịu trách nhiệm tuân thủ các điều khoản đó và luật bản quyền nơi bạn sống.
